# nfs-link.service

Сервис идёт в паре с uuid-mount.service. В факультетской сетевой загрузке uuid-mount.service, помимо прочих файловых систем, монтирует сетевую файловую систему, содержащую домашние каталоги пользователей в точку /mnt/nfs. Сервис nfs-link.service создаёт ссылку на ваш сетевой домашний каталог в файле $HOME/NET при его успешном монтировании.
